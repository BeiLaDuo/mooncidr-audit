# MoonCIDR Audit 项目申报书

项目名称：MoonCIDR Audit：面向网关、代理与运维配置的 IPv4/CIDR 规则审计库

参赛者：高本乾

仓库链接：https://github.com/BeiLaDuo/mooncidr-audit

项目定位：本项目是一个原创 MoonBit 开源库，面向网关、反向代理、云安全组、访问控制列表和运维脚本中的 IPv4/CIDR 规则，提供解析、匹配、冲突检测、遮蔽检测、网段聚合、覆盖空洞分析、配置导入和审计报告能力。

现有基础：已完成 IPv4 解析、CIDR 归一化、有序 allow / deny 规则解析、首个命中规则决策、规则集审计、规则集变更对比、修复建议、网段聚合、地址区间合并、覆盖空洞分析、Nginx 与 CSV 规则导入、CI 发布门禁、文本报告、JSON 风格报告、命令行演示和示例场景。仓库现有 4,003 行有效 MoonBit 代码，其中生产代码 3,010 行、测试代码 993 行；117 个测试已全部通过，可使用 moon check、moon build、moon test 复验。

计划内容：在当前可运行版本上继续补充 CIDR 边界与异常输入测试，稳定报告字段，完善典型网关与云安全组样例，验证 GitHub CI，整理 Mooncakes 发布信息、版本记录和提交材料。后续根据实际需求评估 IPv6 或离线云厂商规则导入适配，核心项目仍保持离线审计边界。

技术路线：项目使用 UInt 表示 IPv4 地址，基于前缀掩码计算网络地址和广播地址，提供包含、重叠、等价范围等基础操作。规则集按顺序执行，审计器分别分析单条规则和规则对。聚合器负责去重、包含消除和兄弟网段合并，区间分析器计算覆盖空洞，导入层把外部文本转换为统一规则，发布门禁根据风险阈值输出自动决策。

预期成果：公开 MoonBit 代码仓库、README、可运行示例、测试用例、CI、Apache-2.0 许可证、项目申报书、查重说明、Mooncakes 软件包和后续维护计划。项目核心功能保持边界清晰，便于作为 MoonBit DevOps 工具和配置检查工具的基础组件。本项目为原创项目，不是对现有第三方项目的直接移植。

创新价值：MoonCIDR Audit 不只是 IP 解析器，而是面向真实运维配置的规则审计库。经公开生态查重，未发现高度重合的 MoonBit 公开项目；它能回答“这组规则实际会怎样执行”“哪些规则有风险或不会生效”“网段能否进一步聚合”和“目标网络存在哪些覆盖空洞”，与普通 URL、socket 或基础网络示例形成明显差异。
