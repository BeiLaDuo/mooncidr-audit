## 项目简介

MoonCIDR Audit 是一个使用 MoonBit 实现的 IPv4/CIDR 规则审计库，面向网关、反向代理、云安全组、访问控制列表和运维脚本中的 `allow` / `deny` 规则。项目不实现防火墙、代理服务或真实网络控制，而是提供可复用的离线分析能力，帮助开发者在规则上线前发现规则遮蔽、冲突重叠、过宽放行、全局拒绝、非规范 CIDR、重复配置、覆盖空洞和可聚合网段等问题。

## 核心功能范围

- 提供 IPv4 地址、CIDR 块、规则、规则集、审计发现、风险等级和发布门禁等核心数据模型；
- 支持 IPv4 解析、CIDR 归一化、地址包含、网段重叠、等价范围、特殊地址分类和首条命中规则决策；
- 支持重复规则、遮蔽规则、冲突重叠、冗余重叠、过宽放行、全局拒绝和非规范 CIDR 输入检测；
- 支持规则集变更对比、修复建议生成、地址区间合并、覆盖空洞分析和 CIDR 去重聚合；
- 支持原生规则文本、Nginx `allow` / `deny` 指令和 CSV 规则表导入，并能报告错误行；
- 支持文本报告、Markdown 表格、JSON 风格报告和 CI 发布门禁结果；
- 提供主演示、网关示例、云安全组示例、README、查重说明、提交清单和 Mooncakes 发布材料。

## 项目预期目标和技术路线

项目使用 `UInt` 表示 IPv4 地址，基于前缀掩码计算网络地址和广播地址，避免边界地址超过有符号整数范围。CIDR 层提供包含、重叠、归一化和地址范围转换；规则层按照配置顺序执行，用首个匹配规则解释最终动作；审计层分别分析单条规则和规则对，输出结构化风险发现；聚合层负责去重、包含消除和兄弟网段合并；覆盖分析层把网段转为闭区间并计算目标网络中的空洞；导入层把外部文本转换为统一规则模型；门禁层根据严重问题数、警告数和风险分数给出 CI 是否通过的判断。预期成果是一个边界清楚、测试充分、文档完整、可长期维护的 MoonBit 网络配置审计基础库。

## 开源与创新价值

本项目采用 OSI 认可的 Apache-2.0 许可证，核心代码为原创 MoonBit 实现，不包含私有代码、闭源代码、商业代码或来源不明内容。经公开生态查重，未发现与本项目功能高度重合的 MoonBit 公开项目。MoonCIDR Audit 的价值不只是解析 IP 或 CIDR，而是面向真实运维配置回答“规则实际会怎样执行”“哪些规则有风险或不会生效”“网段是否可以进一步聚合”“目标网络存在哪些覆盖空洞”等问题，可作为后续 MoonBit DevOps 工具、配置 Linter、网关规则检查器和教学示例的基础组件。
