# MoonCIDR Audit 项目申报书

项目名称：MoonCIDR Audit：面向网关、代理与运维配置的 IPv4/CIDR 规则审计库

参赛者：高本乾

GitHub 账号：BeiLaDuo

项目仓库：https://github.com/BeiLaDuo/mooncidr-audit

## 一、项目背景

网关、反向代理、安全组、访问控制列表和运维脚本中经常出现 IPv4/CIDR 规则。实际配置里常见的问题包括规则顺序错误、后续规则被前序规则遮蔽、过宽的放行网段、全局拒绝规则、CIDR 主机位未归零，以及私有地址、回环地址、链路本地地址和组播地址被误写入外部访问策略。

MoonCIDR Audit 希望补齐 MoonBit 生态中面向网络规则审计的小型基础库能力。它不实现防火墙或网络服务，而是提供可复用的 CIDR 解析、规则匹配、冲突检测、网段聚合、覆盖空洞分析、离线配置导入、变更对比、修复建议和报告输出能力，便于后续集成到 CI、配置检查工具、教学示例和 MoonBit 运维工具中。

## 二、项目类型

本项目属于原创 MoonBit 开源库，核心逻辑使用 MoonBit 实现。项目包含库代码、测试、命令行演示、示例场景、README、查重说明和申报材料。

## 三、现有基础

当前已完成项目骨架、IPv4 解析、CIDR 归一化、规则解析、审计策略、规则集变更对比、修复建议、地址区间合并、CIDR 聚合、覆盖空洞分析、Nginx 与 CSV 配置导入、CI 发布门禁、报告输出、示例程序和单元测试。仓库现有 4,003 行有效 MoonBit 代码，其中生产代码 3,010 行、测试代码 993 行；117 个测试已全部通过。项目可以通过 `moon check`、`moon build` 和 `moon test` 复验。

## 四、本次计划开发内容

计划在当前可运行版本上继续完成发布级收尾，重点包括：补充更多 CIDR 边界与异常输入测试，稳定文本、Markdown 和 JSON 风格报告字段，完善典型网关与云安全组示例，验证 GitHub CI，整理 Mooncakes 发布信息，补充限制说明、版本记录和后续维护路线。后续扩展将继续坚持离线审计边界，不接触真实防火墙、云厂商凭据或在线网络控制。

## 五、技术路线

项目使用 `UInt` 表示 IPv4 地址，避免 `255.255.255.255` 等地址超过有符号整数范围导致的边界问题。CIDR 通过前缀掩码计算网络地址和广播地址，并提供包含、重叠、等价范围等基础操作。规则集按照配置顺序执行，用首个匹配规则决定 IP 的最终动作。审计器对单条规则和规则对分别分析，输出结构化发现和可读报告。聚合器通过去重、包含消除和递归兄弟网段合并缩减 CIDR 列表；覆盖分析器将网段转换为闭区间并计算目标网络中的未覆盖空洞；导入层负责把 Nginx 与 CSV 文本转换为统一规则模型；发布门禁按照严重问题数、警告数和风险分数给出自动通过或阻断结果。

## 六、预期功能

- 解析 IPv4 地址和 CIDR 块；
- 归一化非标准 CIDR 输入；
- 识别私有、回环、链路本地、组播、未指定和广播地址；
- 解析有序 `allow` / `deny` 规则；
- 判断某个 IP 命中的第一条规则；
- 检测重复、遮蔽、冲突重叠、冗余重叠、过宽放行和全局拒绝；
- 对比两版规则集，识别新增、删除、动作变更和备注变更；
- 根据审计发现生成修复建议；
- 合并重叠或相邻地址区间，并查找目标网段内的覆盖空洞；
- 去除重复和被包含网段，递归合并相邻兄弟 CIDR；
- 导入 Nginx `allow` / `deny` 指令和 CSV 规则表，并报告错误行；
- 根据可配置阈值生成 CI 发布门禁结果；
- 输出文本报告、Markdown 表格和 JSON 风格报告；
- 提供可运行示例、测试和 CI。

## 七、测试与文档

项目包含 117 个测试，覆盖解析、CIDR 计算、规则匹配、策略差异、网段聚合、区间覆盖、配置导入、发布门禁、变更对比、修复建议和报告输出。README 提供快速开始、基础用法、示例输出、API 概览和项目边界。`docs/novelty-review.md` 说明项目与现有 MoonBit 生态的差异，`docs/submission-checklist.md` 用于提交前自查。

## 八、开源许可证

项目采用 OSI 认可的 Apache-2.0 许可证。本项目为原创项目，不是对现有第三方项目的直接移植；当前核心库不包含外部运行时依赖，也不包含私有代码、闭源代码或来源不明代码。若后续参考或引入第三方实现，将补充来源、许可证、适配范围和未支持功能说明。

## 九、生态价值

MoonCIDR Audit 的价值在于提供一个小而清晰的 MoonBit 网络配置审计组件。经公开生态查重，未发现与本项目功能高度重合的 MoonBit 公开项目；项目既可以作为独立库使用，也可以作为后续 MoonBit DevOps 工具、配置 Linter、网关规则检查器和教学示例的基础能力。
