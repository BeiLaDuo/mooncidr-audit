## 项目简介

MoonCIDR Audit 是一个使用 MoonBit 实现的 IPv4/CIDR 规则审计库，面向网关、反向代理、云安全组、访问控制列表和运维脚本中的 `allow` / `deny` 规则。实际配置中常见的问题包括规则顺序错误、后续规则被前序规则遮蔽、过宽的放行网段、全局拒绝规则、CIDR 主机位未归零、重复配置、冲突重叠，以及私有地址、回环地址、链路本地地址和组播地址被误写入外部访问策略。

项目不实现防火墙、代理服务、包过滤器或真实网络控制，而是提供可复用的离线分析能力，帮助开发者在规则上线前发现风险，生成可读报告，并在 CI 或配置检查工具中做自动门禁。它适合作为 MoonBit DevOps 工具、配置 Linter、网关规则检查器、教学示例和运维自动化工具的底层组件。

## 核心功能范围

- 提供 IPv4 地址、CIDR 块、规则、规则集、审计发现、风险等级和发布门禁等核心数据模型；
- 支持 IPv4 解析、CIDR 归一化、地址包含、网段重叠、等价范围、特殊地址分类和首条命中规则决策；
- 支持重复规则、遮蔽规则、冲突重叠、冗余重叠、过宽放行、全局拒绝和非规范 CIDR 输入检测；
- 支持严格、网关和安静三类审计策略，便于不同使用场景调整风险阈值；
- 支持规则集变更对比，识别新增、删除、动作变更和备注变更；
- 支持根据审计发现生成修复建议，方便人工审阅和后续工具集成；
- 支持地址区间合并、目标网络覆盖空洞分析、重复网段消除和兄弟 CIDR 递归聚合；
- 支持原生规则文本、Nginx `allow` / `deny` 指令和 CSV 规则表导入，并能报告错误行；
- 支持文本报告、Markdown 表格、JSON 风格报告和 CI 发布门禁结果；
- 提供主演示、网关示例、云安全组示例、README、查重说明、提交清单和 Mooncakes 发布材料。

## 项目现有基础

项目已经形成可构建、可测试、可发布的 MoonBit 仓库。当前有效 MoonBit 代码约 4,003 行，其中生产代码 3,010 行、测试代码 993 行；已有 117 个测试，覆盖解析、CIDR 计算、规则匹配、审计策略、规则变更、修复建议、区间覆盖、网段聚合、配置导入、报告输出和发布门禁。项目已配置公开 GitHub 仓库、GitHub Actions CI、Apache-2.0 许可证、README、示例工程和 Mooncakes 包发布信息，可通过 `moon check`、`moon build`、`moon test` 和 `moon package --list` 复验。

当前已实现的主要模块包括：

- `ip.mbt` 和 `cidr.mbt`：IPv4 与 CIDR 基础模型；
- `rule.mbt`、`policy.mbt` 和 `audit.mbt`：规则解析、审计策略和风险检测；
- `diff.mbt` 和 `hints.mbt`：规则集变更对比与修复建议；
- `ranges.mbt` 和 `aggregate.mbt`：覆盖区间分析与 CIDR 聚合；
- `importer.mbt`：Nginx 与 CSV 等文本规则导入；
- `report.mbt`、`explain.mbt` 和 `gate.mbt`：报告渲染、命中解释和 CI 门禁；
- `cmd/main` 与 `examples`：可运行演示和典型场景。

## 项目预期目标和技术路线

项目使用 `UInt` 表示 IPv4 地址，基于前缀掩码计算网络地址和广播地址，避免 `255.255.255.255` 等边界地址超过有符号整数范围。CIDR 层提供包含、重叠、归一化和地址范围转换；规则层按照配置顺序执行，用首个匹配规则解释最终动作；审计层分别分析单条规则和规则对，输出结构化风险发现；聚合层负责去重、包含消除和兄弟网段合并；覆盖分析层把网段转为闭区间并计算目标网络中的空洞；导入层把外部文本转换为统一规则模型；门禁层根据严重问题数、警告数和风险分数给出 CI 是否通过的判断。

预期目标是交付一个边界清楚、测试充分、文档完整、可长期维护的 MoonBit 网络配置审计基础库。项目强调确定性输出和可解释结果，同一组输入应得到稳定的审计发现、风险等级和报告文本，方便接入自动化流程。

## 生态价值

经公开生态查重，未发现与本项目功能高度重合的 MoonBit 公开项目。MoonCIDR Audit 的价值不只是解析 IP 或 CIDR，而是面向真实运维配置回答“规则实际会怎样执行”“哪些规则有风险或不会生效”“网段是否可以进一步聚合”“目标网络存在哪些覆盖空洞”等问题。它与普通 URL、socket、HTTP 示例或基础网络解析库形成明显差异，能够补齐 MoonBit 生态中网络配置审计和 DevOps 检查方向的小型基础能力。
